- Corrige o script de entrada gerado para o shell: um alias ou uma função do usuário com o mesmo nome de um agente (como `pi`) quebrava o parser do zsh e do bash a cada inicialização do terminal, exibindo erro e o aviso do instant prompt do Powerlevel10k.
- As funções agora usam a palavra-chave `function`, que o parser não expande como alias, e o guard continua preservando função, alias e configuração do usuário.

Após atualizar, abra um terminal novo para recarregar o script de entrada. Quem já tinha alias com nome de agente mantém o alias; o wrapper da ilha entra apenas onde não há conflito.
